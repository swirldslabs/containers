Configuring floating licenses in end-user installations

ej-technologies' products offer a floating license mode in the license dialog. Choose Help->Enter License Key from the main menu in the JProfiler GUI or the install4j IDE and select the Floating license radio button.

The "Name" and "Company" fields are informational only, unless you choose to restrict the allowed values for the "Name" field as described in README.TXT. In the license server field you have to enter the hostname of the computer where the license server is running. Instead of a host name, an IP address can also be used.

If have a floating license for a certain major version of a product, you can use older versions of the same product with that floating license as well.


Configuring floating licenses on the server

All floating license keys are stored in the file 

    license.txt

in the installation directory. The license file must contain at least one valid floating license for the license server to start up successfully.

To add new license keys, you can run the updateLicenseKeys executable. The license file must contain one floating license key per line, comments start with '#'.

This information is also available in README.TXT. Please see that documentation for help on how to start the license server as a service and on how to enable encryption and mutual authentication. Should you require any additional assistance, please contact 

    support@ej-technologies.com
